# SkillBridge

Биржа специалистов: каталог, вход через Telegram, кабинеты клиента и специалиста, заказы, админка. Работает на Cloudflare Workers + D1.

- `dist/skillbridge-worker.js` — готовый файл для вставки в Cloudflare Worker.
- `src/` — исходники: `server.js` (сервер), `page.html` (страница), `courses.txt` (курсы). После правок: `python3 build.py`.
- `dist/preview.html` — демо-версия страницы без сервера.

## Как запустить SkillBridge: каталог, вход через Telegram, кабинет и заказы

Понадобится 20–30 минут. Всё бесплатно (Cloudflare Workers + база D1 на бесплатном тарифе).

## 1. Создайте бота
1. Откройте в Telegram **@BotFather** → `/newbot`.
2. Задайте имя (например, `SkillBridge`) и логин (например, `skillbridge_tj_bot`). Логин понадобится в шаге 4.
3. Сохраните **токен** вида `1234567890:AA...`. Никому его не показывайте.
4. Найдите своего бота и нажмите **Start**.

## 2. Узнайте свой ID
Откройте **@userinfobot** → Start. Он пришлёт ваш **Id** (число). С этим ID вы будете администратором сайта.

## 3. Создайте базу данных
1. Зарегистрируйтесь на **dash.cloudflare.com**.
2. **Storage & Databases → D1 → Create database**, имя `skillbridge` → **Create**.
   Таблицы создавать не нужно: сайт сделает их сам при первом запуске.

## 4. Создайте сайт (Worker)
1. **Workers & Pages → Create → Create Worker** → имя `skillbridge` → **Deploy**.
2. **Edit code** → удалите всё → вставьте содержимое файла `dist/skillbridge-worker.js` → **Deploy**.
3. **Settings → Bindings → Add → D1 database**: Variable name `DB`, база `skillbridge`.
4. **Settings → Variables and Secrets → Add**:
   - `BOT_TOKEN` — тип **Secret** — токен из шага 1;
   - `BOT_USERNAME` — тип **Text** — логин бота без @;
   - `ADMIN_ID` — тип **Text** — ваш ID из шага 2.
5. Сохраните. Адрес сайта будет вида `skillbridge.<ваш-логин>.workers.dev`.

## 5. Разрешите вход через Telegram на вашем домене
В **@BotFather** → `/setdomain` → выберите бота → отправьте адрес сайта без https, например `skillbridge.<ваш-логин>.workers.dev`.
Без этого кнопка «Войти через Telegram» не появится.

## 6. Проверьте
1. Откройте сайт → **Войти** → войдите через Telegram. У вас появится вкладка **Администрирование**.
2. Во вкладке **Анкета специалиста** заполните тестовую анкету → вам придёт уведомление → одобрите её в **Администрировании**.
3. С другого аккаунта Telegram закажите работу у этого специалиста → уведомления придут вам и специалисту.

## Как это работает
- **Регистрация** — автоматически при первом входе через Telegram. Паролей нет.
- **Клиент** заказывает работу у специалиста из каталога или «любого» (тогда вы назначаете исполнителя в админке). Статус заказа виден в кабинете, изменения приходят в Telegram.
- **Специалист** заполняет анкету → она попадает к вам на проверку → после одобрения появляется в каталоге. Специалист принимает или отклоняет заказы и отмечает «Выполнено».
- **Администратор (вы)** — одобряет/отклоняет анкеты, видит все заказы, назначает исполнителя, получает уведомления обо всём.

## Курсы, сертификаты и удостоверения
- **Курсы** — уроки с текстом, тест после каждого урока (зачёт от 70%) и итоговый экзамен (от 70%, до 5 попыток в сутки). Прогресс сохраняется в кабинете.
- **Сертификат** выдаётся за каждый сданный курс, **удостоверение** — когда сданы все курсы программы. У каждого документа уникальный номер (SB-2026-XXXXXXXX) и страница проверки `/cert/<номер>`; общая проверка — `/verify`. Документ можно сохранить в PDF кнопкой «Скачать PDF / печать».
- Администратор видит все выданные документы и может аннулировать документ.
- Документы SkillBridge подтверждают прохождение обучения на платформе и не являются документами об образовании государственного образца.

### Как добавить или изменить курс
Все курсы лежат в одном файле `src/courses.txt` — формат описан в его начале:
```
=== COURSE id_kursa
title: Название курса
title_en: Course title
track: excel            (направление из списка на сайте, можно оставить пустым)
level: Начальный
hours: 6                (академические часы — печатаются в сертификате)
summary: Одна строка для карточки
about: Описание для страницы курса

--- LESSON Название урока
Текст урока. Поддерживаются ### заголовки, списки «* », нумерация «1. », **жирный**, `код` и блоки кода ```.

?? Вопрос теста
- неверный вариант
+ верный вариант
- неверный вариант

--- EXAM
?? Вопрос экзамена
+ верный
- неверный

=== PROGRAM id_programmy
title: Название программы (удостоверение)
courses: id1, id2, id3
summary: Описание
```
После правок выполните `python3 build.py` и вставьте новый `dist/skillbridge-worker.js` в Cloudflare. Номера уроков в курсе лучше не переставлять после запуска — прогресс учеников привязан к номеру урока.

## Свой домен (по желанию)
Купите домен (например, skillbridge.tj), добавьте его в Cloudflare → в воркере **Settings → Domains & Routes → Add → Custom domain**. Затем повторите шаг 5 с новым доменом.
